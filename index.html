The question everyone asks first

Will this get me banned?

No. Here is exactly why, so you can judge it for yourself rather than taking our word for it.

Nothing touches the game

No memory reading, no injection, no modified files, no automation of any input. Apex runs exactly as it ships.

Stats come from a public API

The rank overlay asks Apex Legends Status — a long-running community stats service — for your public profile. Same data anyone can look up on their site.

Live events come from Overwolf

The upcoming FX read match events through Overwolf's official game-events API, the sanctioned route thousands of Apex apps already use.

Your key stays yours

The overlay talks to exactly one place: the stats API. No analytics, no telemetry, nothing phones home to us. There is no account to make.

Before you buy

Straight answers

What do I actually get?

A single HTML file. You open it once in your browser, it walks you through getting a free API key and entering your name, then it builds you a personalised copy. You add that copy to OBS as a browser source. That's it — no installer, nothing running in the background.

Do I need to know how to code?

No. You never open it in a text editor. The built-in setup guide handles everything and tells you exactly what's wrong if something doesn't connect.

Does it cost anything to run?

No. The stats API key is free, and the overlay makes one request a minute — nowhere near the free tier's limit, even with several overlays open.

Console?

Yes. Pick PlayStation or Xbox during setup. You still run OBS on a PC; the overlay just looks up your console account.

Streamlabs or OBS.Live?

Both work. They use the same browser source under the hood.

Two accounts?

Run the setup guide twice. Each run builds its own file, named after that player, so they can't overwrite each other. Add a browser source for each.

What if a new season changes the RP thresholds?

There's a plain table of tier costs near the bottom of the file you can edit in Notepad — and updates go out when Respawn changes them.

Can I put my own branding on it?

Yes — it's plain HTML and CSS, and modifying your copy for your own streams is explicitly allowed. Reselling it or passing it around isn't.
